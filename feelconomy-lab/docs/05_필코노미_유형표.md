# 필코노미 유형표 (FEELCONOMY TYPE)

MBTI처럼 참가자가 오래 기억할 수 있는 고정 유형 체계입니다. 이 문서는
[`src/config/feelconomyTypes.ts`](../src/config/feelconomyTypes.ts)와
[`src/lib/math/typeCode.ts`](../src/lib/math/typeCode.ts)의 내용을 사람이
읽기 좋은 형태로 정리한 것입니다.

---

## 0. 왜 이 체계를 별도로 만들었는가

이 사이트의 핵심 계산(SVD → 개인별 잠재공간 → K-means)은 **참가자마다 완전히
다른 좌표계**를 만듭니다. 그래서 "군집 1"이라는 이름이 어떤 사람에게는 조용한
성향을, 다른 사람에게는 전혀 다른 조합을 가리킬 수 있습니다 — 계산은 정확하지만,
참가자 입장에서는 "내가 다음 주에도 기억할 수 있는 정체성"이 되기 어렵습니다.

그래서 SVD/K-means와는 **완전히 독립적으로**, 참가자가 입력한 현재 감성욕구
q(6개) 자체를 3개의 이분법 축으로 나눠 **고정된 8가지 유형** 중 하나로
분류하는 체계를 추가했습니다. MBTI가 4개 이분 축(E/I, S/N, T/F, J/P)으로
16가지 코드를 만드는 것처럼, 이 체계는 3개 이분 축으로 8가지 코드를 만듭니다.

### 두 체계의 역할 차이 (참가자에게도 항상 함께 안내됩니다)

| | 필코노미 유형 | 잠재수요 분석 (SVD/K-means) |
|---|---|---|
| 입력 | 현재 감성욕구 q (6개)만 | q + 소비대안 평가행렬 A (8×6) |
| 결과 | 고정된 8종 중 하나 (모든 참가자가 같은 8종을 공유) | 참가자마다 다른 좌표계에서 만들어진 군집 |
| 성격 | 지금 이 순간의 정체성 요약 (MBTI와 비슷한 성격) | 데이터 기반 탐색적 추정 (거리 계산) |
| 안정성 | 오늘 다시 하면 바뀔 수 있음 (다른 성격 검사와 동일) | 같은 입력이면 항상 같은 결과 (재현성 보장) |
| 목적 | 기억하기 쉬운 정체성, 재미, 공유 | 오늘 이 순간의 소비 방향 탐색 |

**주의**: 필코노미 유형은 성격을 과학적으로 규정하는 진단 도구가 아닙니다.
MBTI와 마찬가지로 "지금 이 순간의 자기보고를 8개의 틀로 요약한 것"이며,
사이트 곳곳에서 이 점을 참가자에게 명시합니다 (TypeRevealPage의 안내문 참고).

## 1. 3가지 판정 기준

감성욕구 6개를 서로 대비되는 3쌍으로 정확히 나눴습니다 — 축 하나도 남기지
않고 3쌍으로 묶은 것이라, 유형 체계가 기존 감성욕구 설정과 완전히 맞물립니다.

| 기준 | 질문 | 양의 문자 | 음의 문자 |
|---|---|---|---|
| **에너지 방향** | 지금 나는 짜릿함을 원할까, 편안함을 원할까? | **S**park = 자극·설렘 | **R**est = 회복·안정 |
| **마음의 초점** | 지금 나는 나를 표현하고 싶을까, 함께하고 싶을까? | **M**e = 자기표현 | **W**e = 소속·교류 |
| **원하는 보상** | 지금 나는 이뤄내고 싶을까, 그냥 즐기고 싶을까? | **G**oal = 성취·효능감 | **J**oy = 즐거움 |

**판정 규칙**: 각 기준에서 두 감성욕구 점수를 비교해 더 높은 쪽의 문자를
채택합니다. 코드는 세 문자를 순서대로 이어 붙입니다 (예: 자극·설렘이
회복·안정보다 높고, 자기표현이 소속·교류보다 높고, 성취·효능감이 즐거움보다
높으면 → **SMG**).

**동점 처리 규칙**: 두 점수가 정확히 같으면 **항상 양의 문자(S, M, G)**를
채택합니다. "능동적으로 원하는 쪽을 우선한다"는 하나의 일관된 규칙이며, 세
기준 모두에 예외 없이 적용해 같은 입력에는 항상 같은 유형이 나오게 합니다
(코드: `positiveScore >= negativeScore` 이면 양의 문자).

## 2. 8가지 유형 전체표

| 코드 | 이름 | 태그라인 | 대표 색 | 잘 어울리는 소비 예시 |
|---|---|---|---|---|
| 🧭 **SMG** | 반짝이는 개척자 | "짜릿함으로 나만의 길을 만든다" | 테라코타 `#E2704A` | 여행·체험, 패션 |
| 🎈 **SMJ** | 반짝이는 자유영혼 | "순간의 짜릿함을 온전히 나답게 즐긴다" | 코랄 `#EF8D6C` | 게임, 콘텐츠·구독 |
| 🔥 **SWG** | 열정적인 리더 | "함께 짜릿하게, 함께 이뤄낸다" | 파프리카 레드 `#CF5B4A` | 여행·체험, 문화·공연 |
| 🎉 **SWJ** | 신나는 무드메이커 | "함께 있을 때 가장 즐겁다" | 앰버 `#E7A240` | 문화·공연, 식음료 |
| 🌱 **RMG** | 차분한 완성가 | "조용히, 그러나 확실하게 이뤄낸다" | 세이지 그린 `#7FAE7A` | 생활·실용, 콘텐츠·구독 |
| 🕯️ **RMJ** | 고요한 탐닉가 | "나만의 시간 속에서 작은 행복을 찾는다" | 웜 브라운 `#A97C50` | 카페·디저트, 콘텐츠·구독 |
| 🤝 **RWG** | 든든한 동행자 | "함께라서 더 단단해진다" | 더스티 골드 `#D4B36A` | 생활·실용, 식음료 |
| ☕ **RWJ** | 포근한 나눔러 | "편안한 분위기에서 함께 웃는 게 좋다" | 더스티 로즈 `#E0959D` | 카페·디저트, 식음료 |

### 각 유형 상세 설명

**🧭 SMG · 반짝이는 개척자**
새로운 자극 속에서 스스로 성장하는 것을 즐기는 유형입니다. 낯선 도전과
경험을 통해 나다움을 확인하고, 그 과정 자체에서 성취감을 느낍니다.

**🎈 SMJ · 반짝이는 자유영혼**
즉흥적이고 자유로운 성향으로, 강렬한 즐거움을 나만의 방식으로 만끽합니다.
정해진 틀보다 지금 이 순간의 재미를 우선합니다.

**🔥 SWG · 열정적인 리더**
사람들과 함께 도전하고 성장하는 데서 에너지를 얻는 유형입니다. 목표를 향해
사람들을 이끌고 함께 나아가는 것을 즐깁니다.

**🎉 SWJ · 신나는 무드메이커**
사람들과 함께 신나는 순간을 만드는 분위기 메이커입니다. 즐거움은 나눌 때
배가 된다고 믿습니다.

**🌱 RMG · 차분한 완성가**
안정된 상태에서 스스로 계획하고 하나씩 성취해가는 유형입니다. 혼자만의
속도로 꾸준히 나아가는 것을 편안해합니다.

**🕯️ RMJ · 고요한 탐닉가**
혼자만의 편안한 시간 속에서 소소하지만 확실한 즐거움을 찾는 유형입니다.
조용한 몰입이 가장 큰 힐링입니다.

**🤝 RWG · 든든한 동행자**
신뢰하는 사람들과 안정적으로 성장해가는 것을 선호하는 유형입니다. 조급하지
않게, 함께 오래가는 관계를 중요하게 여깁니다.

**☕ RWJ · 포근한 나눔러**
따뜻하고 편안한 분위기 속에서 사람들과 소소한 즐거움을 나누는 유형입니다.
거창하지 않아도 함께라면 충분합니다.

## 3. 계산 예시

현재 욕구 q = [즐거움 8, 자극·설렘 9, 회복·안정 3, 소속·교류 7, 자기표현 8, 성취·효능감 4]

| 기준 | 비교 | 결과 |
|---|---|---|
| 에너지 방향 | 자극·설렘(9) ≥ 회복·안정(3) | **S** |
| 마음의 초점 | 자기표현(8) ≥ 소속·교류(7) | **M** |
| 원하는 보상 | 성취·효능감(4) < 즐거움(8) | **J** |

→ 코드 **SMJ · 반짝이는 자유영혼**

이 예시는 [`04_수학_계산_설명.md`](04_수학_계산_설명.md)에서 잠재수요 분석의
worked example로 쓴 것과 같은 욕구 벡터입니다 — 같은 참가자가 "필코노미
유형"과 "오늘의 잠재수요 분석"을 모두 받으면 이런 식으로 두 결과가 함께
나타납니다: 유형은 **SMJ(반짝이는 자유영혼)**, 잠재수요는 **즐거움·자극추구형
군집 → 문화·공연**. 서로 다른 질문에 답하는 두 결과가 자연스럽게 겹치는
지점을 보여주는 사례입니다.

## 4. 어디에 쓰이는가

| 위치 | 내용 |
|---|---|
| `/type` (TypeRevealPage) | 욕구 입력 직후, MBTI 결과 화면처럼 유형을 공개. 3가지 기준의 점수 비교를 막대로 보여준다. 다른 7개 유형도 둘러볼 수 있다. |
| `/result` (ResultPage) | 유형 배지를 잠재수요 분석 결과 위에 함께 표시해 "정체성"과 "오늘의 데이터 분석"을 연결한다. |
| `/finish` (FinishPage) | 마무리 화면에서 유형을 다시 한번 상기시켜 기억에 남게 한다. |
| 관리자 → 분석 규격 탭 | 이 문서의 표를 그대로 보여준다. |
| 관리자 → 참가자 데이터 탭 / CSV | 참가자별 유형 코드를 조회·내보내기할 수 있다 (연구용 집계에 활용 가능). |

## 5. 수정 방법

이름·태그라인·설명·색·예시를 바꾸려면
[`src/config/feelconomyTypes.ts`](../src/config/feelconomyTypes.ts) 하나만
수정하면 됩니다. 판정 기준(어떤 욕구 쌍을 비교할지)을 바꾸려면 같은 파일의
`TYPE_DIMENSIONS` 배열을 수정하세요. 어느 쪽을 바꾸든 8가지 코드 전체
(`FEELCONOMY_TYPES`)에 이름이 채워져 있는지 단위 테스트
(`src/lib/math/math.test.ts`의 `typeCode` describe 블록)가 확인합니다.
